# Project 5 · Monthly sales summary with Python

> ⚠️ **Fictional data.** The sales in this project are generated by a script on purpose, for practice. They don't belong to any real company.

## The problem
The "pocket CFO" from [project 1](../01-mapa-proceso/) needs the clothing brand's numbers every month: revenue, returns, margin and comparison with the previous month. Calculating them by hand in Excel is slow, and some sales come in dollars or pounds.

## The solution
Two Python scripts that only use the standard library (nothing to install):

1. **`generar_datos.py`** creates `ventas_ficticias.csv`: about 1,400 sales lines from 2025 with date, order, product, size, units, price, currency, cost and whether it was returned. It uses a fixed seed, so every run generates exactly the same data.
2. **`resumen_ventas.py`**:
   - converts sales in USD and GBP into euros with the exchange rate of **that same day**, using the API from [project 2](../02-api-json/) with a single request for the whole year;
   - calculates per month the net revenue, returns (in € and %), cost, margin (in € and %) and the change from the previous month;
   - ranks the products by revenue;
   - saves the result in `resumen_mensual.csv`, which project 6 will use.

## How to use it
```bash
python3 generar_datos.py
python3 resumen_ventas.py
```

The jacket is the product with the highest revenue and the T-shirt the lowest.

## Decisions made
- **Returns:** they are subtracted from revenue, and their cost isn't counted because the item goes back to the warehouse. This is an assumption: shipping costs and losses aren't counted either.
- **Return rate:** percentage of order lines returned, not of units or euros.
- **Weekends and holidays:** since there's no official exchange rate on those days, the rate from the last previous business day is used.

## What I learned
- **Reading and writing CSV** with `csv.DictReader` and `csv.DictWriter`: each row is a form with boxes.
- **Grouping by month** with `defaultdict`, like an Excel pivot table.
- **Calling an API from Python** with `urllib`, and what to do if the connection fails.
- **Functions:** splitting the work into small named recipes (`a_euros`, `tipo_del_dia`).
